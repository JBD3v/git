Companion blog posts for each episode: https://github.blog/developer-skills/github/ (search "GitHub for Beginners")

**Complementary resources (core Git practice):**
- Learn Git Branching (interactive, in-browser): https://learngitbranching.js.org/ — do "Main" levels 1–4 and "Remote" levels 1–2

- GitHub Skills (hands-on courses inside real repos): https://skills.github.com/ — "Introduction to GitHub", "Review pull requests", "Resolve merge conflicts"
