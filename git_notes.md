# Git basic commands

## Configure Git

```power_shell
git config --global user.name "Jerome.Bark"
git config --global user.email "jerome.bark@fastmail.com"
git config --list
```

## New repo

```power_shell
git init
git status
```

## Track and Store Changes

```power_shell
git add <file_names or . for all files in current dir>
git commit 
git status
```

## Aliases

```power_shell
git config --global alias.i init
git i
```
