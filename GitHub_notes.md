# GitHub Basics

## The GitHub Flow

```shell
git clone
git checkout -b newbranch
git add .
git commit -m "message"
git push
# open a PR
# merge PR
git branch -d newbranch             # Delete local branch
git push --delete origin newbranch  # Delete remote branch
```
